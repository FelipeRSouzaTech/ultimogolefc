Estrutura de Diretórios

app/              ← Next.js app router (pages public + admin)
├─ (admin)/        ← Rotas administrativas protegidas
├─ (public)/       ← Rotas públicas do site
├─ api/            ← Endpoints API (matches, news, seasons, media)
components/        ← Componentes React reutilizáveis
lib/               ← Utilitários e configurações
  ├─ auth/         ← Auth guard, password policy, sessions
  ├─ db/           ← Prisma client
  ├─ storage/      ← Uploads com SigV4
  └─ validation/   ← Schemas de validação
modules/           ← Lógica de negócio por domínio
  ├─ competitions/
  ├─ gallery/
  ├─ matches/
  ├─ media/
  ├─ news/
  ├─ site/
  ├─ sponsors/
  └─ users/
prisma/            ← Schema e seeds de banco de dados
public/            ← Arquivos estáticos (imagens, icons)
scripts/           ← Scripts auxiliares (create-admin.ts)
tests/             ← Suite de testes (unit + e2e)

Banco de Dados

Utiliza Prisma ORM com PostgreSQL. Schema principal inclui:

  • Clubes, competições e temporadas
  • Matched e resultados de jogos
  • Notícias e mídia (imagens, banners, galeria)
  • Patrocinadores e parcerias
  • Usuários e permissões de acesso
  • Auditoria e logs de alterações
